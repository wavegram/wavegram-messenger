# Privacy Policy

Wavegram Messenger stores account data, messages, profile information, and security events only for providing the messaging service. Direct personal chats use browser-side end-to-end encryption; the server stores only encrypted content for those chats.

We process user registration, account authentication, message delivery, active sessions, moderation reports, and market transactions. Data is not sold. Users can request account deletion from the app or through repository support.

Security data may include phone/account identifiers, public keys, session metadata, login events, and protected two-factor credentials. Security credentials are encrypted or hashed where applicable.

## Service providers

Wavegram uses Cloudflare Workers, Cloudflare D1, and the Telegram authentication bot. GitHub is used for software releases and updates.
